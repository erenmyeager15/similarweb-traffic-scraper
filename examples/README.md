# US agency reporting examples

These three presets are **synthetic report previews**, not real Similarweb traffic,
customer observations or a no-key data source. They create no dataset results and
no `website-scraped` fees. The **$0.00005/GB Actor Start event (minimum one)** and
applicable platform usage can still apply. No schedule or external request is
created. Do not repeat them to inflate Actor metrics.

| Input file | What to inspect |
| --- | --- |
| `us-agency-comparison.json` | `DEMO_COMPARISON.csv`: matching US/month/basis and included-domain share, not market share |
| `us-traffic-change-alerts.json` | `DEMO_ALERTS.csv`: -30% visits, +7 bounce percentage points and +30% numerical rank worsening; exact previous/current evidence |
| `us-scope-audit.json` | `DEMO_QUALITY.csv`: US vs worldwide vs unknown scope, non-adjacent months and missing peer coverage; no false monthly alerts |

`DEMO_AGENCY_REPORT` contains the complete preview evidence and quality summary;
`DEMO_REPORT.md` explains the limits. Every report row is labeled synthetic.

To analyze real data, use `mode: import`, replace illustrative values with an
export you are permitted to process, identify the provider and confirm the rights
yourself. Supply country, device/traffic type, estimated/measured basis and months.
Without matching context, a comparison is unavailable—not zero growth. Import
uses **$0.002 per confirmed saved domain**, once per domain rather than per month
or report, plus the unchanged start event. No automatic rights consent is supplied.

These local examples require the agency-feature build. They are not evidence that
the public Actor already contains those features; the release report records the
tested/published build and whether example landing pages have been created.
